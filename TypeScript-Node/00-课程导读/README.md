# 课程导读

> 这套课程和仓库里其他六套课程性质不同：PI、DeepSeek Harness、Hermes Agent、OpenHarness、OpenClaw、OpenWorker 都是对某一个真实开源项目的源码深度剖析，而这套课程**不依附任何具体开源项目**——它是一份独立的 TypeScript / Node.js 体系化教程，目标读者是"已经会用其他语言写程序，但没有系统学过 TypeScript/Node.js"的开发者。学完这套课程，你会具备读懂前六套课程里那些 TypeScript 源码片段（类型标注、泛型、`async`/`await`、Node.js API 调用）所需要的语言和运行时基础。

## 这门课程是什么，不是什么

这不是一份"TypeScript 是什么、为什么要用类型系统"这种面向零基础程序员的科普教程，也不是某个框架（React/Next.js/NestJS 之类）的应用教程。它假定你已经知道变量、函数、循环、面向对象这些通用编程概念是怎么回事——只是换了一门具体语言和一个具体运行时，需要把"这门语言/这个运行时特有的东西"补齐：TypeScript 的结构化类型系统和类型推断规则、JavaScript 单线程事件循环下的异步编程模型、Node.js 运行时提供的模块系统/文件系统/网络/进程能力，以及把这些东西组织成一个可维护、可发布的真实工程所需要的工程化实践。

课程的写作方式也和前六套"源码剖析"课程不一样：那六套课程摘录的是别人仓库里的真实代码，这套课程的每一段示例代码都是这门课程自己写的、可以独立运行的最小案例，放在 `TypeScript-Node/examples/` 目录下，和正文一一对应。

## 课程设计思路

全课程按"先补齐工具链，再打牢语法与类型系统，再啃异步和运行时这两块硬骨头，最后落到工程化和进阶话题"的顺序组织，分为七章：

1. **环境搭建与工具链**（第 01 章）：Node.js 版本管理、TypeScript 编译器与项目初始化、包管理器与 NPM 生态、开发工具链与调试环境——先把本地开发环境搭起来，后面每一章的示例代码都要能跑。
2. **JavaScript/TypeScript 语法基石**（第 02 章）：值类型与引用类型、作用域与闭包、解构与函数高级用法、ESM 与 CommonJS 两套模块系统、迭代器与生成器——这些是 JS/TS 特有、但很多其他语言背景的开发者容易带着错误直觉踩坑的地方。
3. **TypeScript 类型系统精讲**（第 03 章）：这是全课程分量最重的一章，从基础类型和类型推断，到联合/交叉类型与可辨识联合，到泛型编程，到映射类型/条件类型/模板字面量类型这套"类型层面的计算能力"，到用 `keyof`/`typeof`/`infer` 做类型体操的实战演练，到类与面向对象类型系统，最后是怎么给没有类型的第三方 JS 库手写声明文件——把 TypeScript 当成一门有自己完整计算能力的语言来对待，而不只是"给 JS 加个类型注解"。
4. **异步编程模型**（第 04 章）：JavaScript 的事件循环与任务队列到底是怎么调度的、`Promise`/`async`/`await` 的执行时序细节、错误处理与取消机制（`AbortController`）、并发控制模式（限流、批处理）——异步是 JS/TS 里最容易"代码能跑但心智模型是错的"的部分，这一章把执行顺序讲透。
5. **Node.js 运行时核心**（第 05 章）：模块解析与包系统机制、文件系统与 Buffer 二进制数据、Stream 流式处理、HTTP 与 WebSocket 网络编程、子进程与 Worker Threads、进程生命周期与优雅关闭——这一章讲的是 Node.js 作为运行时（而不是语言）提供的能力，是浏览器端 JS 经验完全覆盖不到的部分。
6. **工程化实践**（第 06 章）：项目结构与代码组织、测试体系与 Node.js 内置 Test Runner、调试与性能剖析与内存泄漏排查、构建打包与 NPM 包发布——把前面学到的语言和运行时知识，用在一个真正要交付、要被别人依赖的项目上。
7. **进阶主题与总结**（第 07 章）：内存模型与垃圾回收、性能优化实战、常见陷阱与最佳实践清单，最后是课程总结与进阶方向——收尾并给出往后继续深入的路线图。

## 配套代码怎么用

`TypeScript-Node/examples/` 目录的子目录结构和正文的章节/文章结构一一对应（比如 03 章第 05 篇的示例代码在 `examples/03-TypeScript类型系统精讲/05-类型体操实战-keyof-typeof-infer/` 下）。跑起来只需要：

```bash
cd TypeScript-Node
npm install          # 只需要执行一次
npx tsx examples/03-TypeScript类型系统精讲/05-类型体操实战-keyof-typeof-infer/xxx.ts
```

`npx tsx` 直接执行 TypeScript 源文件，不需要先手动编译。另外两条经常会用到的命令：

```bash
npm run typecheck    # tsc --noEmit，只做类型检查，不产生任何文件
npm test             # vitest run，跑课程里配套的单元测试
```

课程写作时的原则是：**正文里出现的每一段示例代码和每一处"真实输出"，都先用 `npm run typecheck` 类型检查过、再实际跑过一遍**，输出是复制粘贴的真实结果，不是凭经验编出来的——如果你在自己机器上跑出了不一样的结果，大概率是环境差异（Node.js/TypeScript 版本、操作系统），值得留意而不是默认课程写错了。

## 适合谁学

- 已经会用 Python、Go、Java、C#、Rust 等其他语言写程序，因为工作需要（前端、Node.js 后端、CLI 工具、Electron 应用等）要开始写 TypeScript/Node.js，想要一条系统的学习路径，而不是零散地查文档、看博客；
- 断断续续写过一些 JS/TS，但知识点是碎片化的，尤其是类型系统和异步这两块，想借这个机会补一次系统的课；
- 正在读本仓库其他六套"源码剖析"课程、但发现自己被 TypeScript 类型标注或 `async`/`await` 代码卡住，想先补一下语言基础再回去继续读源码。

## 前置知识

- 具备至少一门其他编程语言的基本编程能力（变量、函数、条件、循环、基础的面向对象概念），**本课程不会讲解这些通用编程概念**；
- 不需要任何 JavaScript/TypeScript/Node.js 的既有经验，课程从环境搭建开始，语法和类型系统都会从零讲起；
- 一台能安装 Node.js 的电脑（macOS/Linux/Windows 均可），第 01 章会讲清楚具体怎么装。
